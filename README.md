# 中庄調節池單車計畫

一個給你「實際去騎這條路線」時使用的手機隨身導覽網頁（PWA）。全程約 25 公里，從中庄調節池出發，途經鶯歌山水步道、大溪橋、大溪老街、月眉人工濕地、山豬湖生態親水園區與中庄吊橋。

## 功能特色

- **互動地圖**：以 Leaflet.js 繪製路線與景點，可切換 Google 道路圖、Google 衛星圖、OpenStreetMap 三種圖層（左上角圖層控制）。
- **即時 GPS 定位**：點擊「我的位置」即可在地圖上顯示並持續追蹤目前所在位置。
- **行程進度**：總長度、累計爬升、休息點數等統計資訊，以及依序排列的路線時間軸。
- **精彩景點**：路線上重點景點的介紹與圖片，點擊卡片可直接跳到地圖上對應位置。
- **老街補給**：大溪老街周邊在地美食與咖啡廳清單，點擊「導航」一鍵開啟 Google 地圖導航。
- **可安裝為 App**：支援加入手機主畫面，全螢幕啟動使用（PWA）。

## 如何使用

### 直接開啟

用瀏覽器打開 `index.html` 即可看到地圖與路線介紹。但受瀏覽器安全性限制，**以本機檔案方式開啟時「我的位置」GPS 定位功能將無法使用**（瀏覽器只允許在 HTTPS 或 localhost 環境下取得定位權限）。

### 部署後使用（建議）

若要在騎車時使用 GPS 即時定位功能，建議將本專案部署到任一支援 HTTPS 的靜態網站服務，例如 GitHub Pages：

1. 在 GitHub 專案的 **Settings → Pages** 中，選擇要發布的分支與根目錄（`/`）。
2. 儲存後，GitHub 會提供一組 `https://` 網址，用手機瀏覽器開啟即可正常使用定位功能。

### 加入手機主畫面

部署完成後，用手機瀏覽器開啟網址，透過瀏覽器選單的「加入主畫面」（或「安裝應用程式」），即可像一般 App 一樣從主畫面全螢幕啟動。

## 介面操作說明

- **地圖**：可拖曳、縮放檢視全程路線；地圖上橘色動態虛線為路線，橘色大頭針為景點、紅色大頭針為美食/咖啡廳，點擊大頭針會彈出簡介與「打開 Google 地圖導航」按鈕。
- **右上角浮動按鈕**：
  - **我的位置**：開始／停止即時 GPS 定位追蹤，會在地圖上以藍點顯示目前位置。
  - **重設地圖**：將視角重新對齊整條路線。
  - **使用說明**：隨時重新開啟 App 內建的操作說明彈窗。
- **底部滑動抽屜**：點擊或向上滑動標題列展開/收合，內含三個分頁：
  - **行程進度**：總長度、累計爬升、休息點數統計，以及依序排列的路線時間軸。
  - **精彩景點**：點擊卡片上的「地圖檢視」可跳到地圖上對應景點位置。
  - **老街補給**：大溪老街周邊美食與咖啡廳，點擊「導航」開啟 Google 地圖導航。

首次開啟 App 時會自動顯示一次操作說明彈窗，之後可透過右上角的「使用說明」按鈕隨時重新查看。

## 路線關鍵點

1. **中庄調整池管理站**（起點/終點）— 設有洗手間、YouBike 租借站、大停車場。
2. **鶯歌山水步道** — 大漢溪畔視野極佳的景觀步道，可遠眺鳶山堰。
3. **大溪橋** — 巴洛克式人行與單車拱橋，通往大溪老街。
4. **大溪老街**（午餐補給）— 和平路老街，聚集眾多百年美食與老宅咖啡廳。
5. **月眉人工濕地**（景觀休息站 1）— 落羽松秘境，是極佳的歇息拍照點。
6. **山豬湖生態親水園區**（景觀休息站 2）— 大自然秘境綠廊，擁有完整生態水池。
7. **中庄吊橋** — 全台最長懸索式自行車吊橋，可俯瞰大漢溪風光。

## 技術架構

本專案沒有使用任何建置工具，是一個零依賴、單一 `index.html` 的靜態網站，CSS 與 JavaScript 皆內嵌於檔案中：

- **地圖**：[Leaflet.js](https://leafletjs.com/)（透過 CDN 載入）
- **定位**：瀏覽器原生 [Geolocation API](https://developer.mozilla.org/docs/Web/API/Geolocation_API)
- **字型**：Google Fonts（Outfit、Noto Sans TC）
- **PWA**：`manifest.json` 定義安裝資訊，`sw.js` 提供 Service Worker

### 檔案結構

```
.
├── index.html      # 主程式（HTML + 內嵌 CSS/JS）
├── manifest.json   # PWA 安裝設定
├── sw.js           # Service Worker
└── img/            # 景點圖片
```

## 已知限制

- GPS 定位功能僅能在 HTTPS 或 localhost 環境下運作，這是瀏覽器的安全性限制，並非本專案的錯誤。
- 路線與景點座標為預先繪製的資料，非即時路況或動態計算。
